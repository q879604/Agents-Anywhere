# 个人自用版 2.1.13

这是 [`q879604/Agents-Anywhere`](https://github.com/q879604/Agents-Anywhere) 的个人自用快照，
不是官方发布的 2.1.13。Android 端基于 `2.1.13`（versionCode 23）构建；服务端改动和 DSH bridge
改动固定在同一标签 `personal-v2.1.13` 下，方便以后复用。

## 客户端

- 平板双栏、侧栏收起和手机单栏布局；
- 附件菜单：照片、拍照、视频、音频、文件、剪贴板、压缩图片；运行时确实提供 `compact` 时显示压缩上下文；
- 上传前图片压缩、流式上传下载和进度显示；
- 终端工作区图片查看，聊天消息内直接显示工作区/命令截图；
- 应用级待发队列：切换对话或普通退到后台后，待发消息继续等待并在当前回复结束后发送；
- 流式时间线、思考链展开和深色键盘相关修复。

## 服务端

- 附件上传 socket → 磁盘流式写入；上传数量上限 10；
- 本地附件流式下载、ETag/If-None-Match 缓存；
- 图片缩略图 WebP 生成与 `thumb` 接口；
- 新增 `pillow>=11` 依赖；不新增数据库迁移。

## DSH Bridge

- `e1d2d43`：preset 隔离时使用原生 compaction fallback；不伪造 `/compact` 聊天文本。

## 已知限制

- Android 待发队列目前是应用进程内队列；手动强制停止 App 或系统彻底回收进程后会丢失。跨进程、跨设备的
  权威队列需要后续把 DSH inbox/queue 暴露到服务端和客户端。
- DSH 原生 compact 是否出现在 runtime catalog 取决于实际 DSH preset/Agent 是否加载了 compaction 服务；
  bridge fallback 已保留，但部署后应按运行实例核验。
- 本发布说明只记录个人自用改动，不替代官方的版本、数据库迁移和兼容性说明。
